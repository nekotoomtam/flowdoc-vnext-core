# Coordination ownership boundary

Core is the storage host only. It is not the semantic owner of Editor or Backend release readiness.

Each repository owns its local implementation, contracts, risks, evidence, release readiness, and Git operations.

Coordination may own exact `TERM-FLOWDOC-DEVELOPMENT-BASELINE` records, repository roles, the compatibility view, global IDs and shared term families, and release-set references.

No worker, queue, scheduler, or remote mutation protocol exists in this coordination layer.

A future transfer is a one-owner atomic relocation. Dual-active copies are forbidden.
